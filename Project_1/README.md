# Project 1: Data Cleaning & Preparation | DecodeLabs Industrial Training

Welcome to my first Data Analytics project as an intern at DecodeLabs! This project focuses on the foundation of data science: **Data Integrity and Cleaning**. 

## 🛠️ Tools & Technologies Used
- **Microsoft Excel** (Data Cleaning, Formulas, Power Query, Formatting)

## 📋 Key Steps & Methodology
1. **Duplicate Check:** Verified and ensured a 0% error rate on unique identifiers by checking and eliminating redundant records.
2. **Missing Values Imputation:** Strategically handled null values across numeric and text columns (e.g., using `MEDIAN` for prices and standardizing text/categories).
3. **Standardization & Formatting:**
   - Standardized dates to **ISO 8601 (`YYYY-MM-DD`)** format.
   - Cleaned text data using `TRIM` and `PROPER` case to fix inconsistent casing and trailing whitespace.
   - Adjusted numeric precision to **2 decimal places** for financial and metric consistency.
4. **Documentation (Change Log):** Created a detailed Change Log tracking all transformations, descriptions, impacts, and resolution statuses (`CR001` - `CR004`).

## 📊 Artifacts
- The cleaned Excel dataset (`Dataset for Data Analytics.xlsx`) containing the structured data sheets and the `Change Log`.
